🚀 Career Compass - AI-Driven Career Guidance Platform
🌟 Key Features
AI-Powered CV Analysis - Deep analysis of resumes with skill gap identification

Personalized Career Recommendations - Tailored job suggestions based on skills and experience

Learning Roadmap Generator - 6-month customized upskilling plans

Job Matching Engine - Integration with Joble API for real job opportunities

RAG Architecture - Retrieval Augmented Generation for accurate AI responses

Secure Authentication - JWT-based user management

Modular Architecture - Scalable backend with clean separation of concerns

🌍 Technology Stack
🏗️ Backend
Runtime: Node.js

Framework: Express.js

Language: TypeScript

Database: MongoDB

AI Integration: Groq API

Vector Database: Weaviate

File Processing: Multer, pdf-parse

Authentication: JWT, bcrypt

🎨 Frontend
Framework: React

Styling: Tailwind CSS

State Management: Zustand

PDF Generation: React-PDF

Drag & Drop: React DnD

🚀 Deployment
Hosting: Microsoft Azure

Domain: Namecheap

SSL: Let's Encrypt

CI/CD: GitHub Actions

🤖 AI Workflow
RAG Implementation Flow
User Uploads Resume → PDF parsed to text

Skill Extraction → Groq API identifies key skills

Vector Embedding → Ollama creates skill embeddings

Semantic Search → Weaviate finds similar jobs

Augmented Generation → Groq generates recommendations using job data
